Kamen Rider Craft · NeoForge

假面騎士伺服器進入須知

照著下面的步驟裝好 NeoForge 和四個必備模組，就能連進假面騎士模組生存伺服器。版本要跟伺服器一樣，差一點就會被擋在門外。

Minecraft
1.21.1
載入器
NeoForge 21.1.262
版本
僅限 Java 版
正版驗證
需要正版帳號

STEP 1安裝 NeoForge 1.21.1

  1. 用官方 Minecraft Launcher 先啟動一次原版 1.21.1，確認能進遊戲。
  2. 到 NeoForge 官網 neoforged.net 下載 1.21.1 的 installer（建議與伺服器相同的 21.1.262），執行後選 Install client。
  3. Launcher 會多出一個 NeoForge 1.21.1 的設定檔，之後都用它開遊戲。

用 Prism Launcher 或 CurseForge App 的話，建立實例時選 Minecraft 1.21.1、載入器選 NeoForge 即可。不要選 Forge、Fabric 或 Quilt。

STEP 2放入必備模組

四個都要裝，版本請用跟伺服器一樣的。全部從 Modrinth 官方頁面下載，選 NeoForge 與 1.21.1 的版本。

Kamen Rider Craft1.1.4主模組。Modrinth 下載頁
GeckoLib4.9.3Kamen Rider Craft 的前置（需要 4.8.4 以上）。Modrinth 下載頁
Player Animation Library1.1.6Kamen Rider Craft 的前置（需要 1.1.4 以上），變身動作靠它。Modrinth 下載頁
Patchouli1.21.1-93遊戲內指南書，Kamen Rider Craft 的說明書靠它顯示。Modrinth 下載頁

模組 .jar 檔放的位置：

  • 官方 Minecraft Launcher：.minecraft/mods/（Windows 在 %appdata%\.minecraft\mods，Mac 在 ~/Library/Application Support/minecraft/mods）
  • Prism Launcher / MultiMC：該實例的 mods/ 資料夾（實例上按右鍵 → 開啟資料夾）
  • CurseForge App：該 Custom Profile 的 mods/ 資料夾（Profile → … → Open Folder）

伺服器另外裝了 Lithium、FerriteCore、ModernFix、Chunky、spark，它們只在伺服器上運作，玩家不用裝。

STEP 3連進伺服器

伺服器透過 Tailscale 連線，不對外公開，位址請直接向服主索取。

  1. 到 tailscale.com/download 安裝 Tailscale 並登入。
  2. 把你登入 Tailscale 用的帳號告訴服主，等服主把你加入或把伺服器分享給你。
  3. 開著 Tailscale，在 Minecraft「多人遊戲 → 新增伺服器」輸入服主給你的位址。

基岩版不能玩：手機、Switch、PS、Xbox 和 Windows 基岩版都無法連線，模組只支援 Java 版。

進服之後中文翻譯與指南書

  • 繁體中文翻譯：第一次進服會跳出「套用假面騎士模組繁體中文翻譯？」，按是就會自動下載並套用（需開著 Tailscale）。接著到「選項 → 語言」選 繁體中文（台灣）。
  • 指南書：第一次進服會自動拿到一本 Kamen Rider Craft 指南書，裡面有各騎士的取得與變身方式（內容是英文）。弄丟了可以用 3 張紙 + 1 個皮革 + 1 個騎士電路板（Rider Circuit）無序合成。
  • 時間暫停：伺服器連續 5 分鐘沒人在線時，日夜、天氣和作物生長會暫停；有人進來就恢復。

STEP 4連不上時看這裡

錯誤訊息意思怎麼處理
missing mods你少裝了伺服器有的模組把訊息列出的模組（照上面的版本）放進 mods/
extra mods你多裝了伺服器沒有、又需要兩邊都有的模組把列出的模組先移出 mods/ 再連；若是純畫面類模組，可改用支援的版本
version mismatch
channel version mismatch		模組版本跟伺服器不同換成跟伺服器一樣的版本（見 STEP 2）
not running NeoForge你用的是原版、Forge 或 Fabric改用 NeoForge 1.21.1 的設定檔開遊戲
Connection timed out連不到伺服器確認 Tailscale 有開、有登入，且服主已經把你加進來
Incompatible mod set整體模組組合對不上先只留四個必備模組測試，能連上後再一個一個加回其他模組

裝了 Sodium、Iris、小地圖、JEI、回放或視角類模組後連不上的話，先把它暫時移出 mods/ 試一次。確定是它造成的，再改用支援 NeoForge 1.21.1 的版本。不需要刪掉整個 .minecraft，也不要下載來路不明的整合包。

STEP 5還是不行，請提供這三樣給服主

  • 完整的錯誤畫面截圖
  • 你的 mods/ 資料夾裡所有檔案的清單（截圖或把檔名貼上來都可以）
  • 最新的用戶端 log：.minecraft/logs/latest.log（Prism/CurseForge 在該實例的 logs/）
